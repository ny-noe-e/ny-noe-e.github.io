# EDELWERK BMW Website

Kurzbeschreibung:  
Dieses Projekt ist eine statische Website fuer eine fiktive BMW-Tuning-Marke. Die Seite praesentiert eine EDELWERK-Modelluebersicht mit zehn verschiedenen BMW-Modellen, generierten Fahrzeugbildern und eigenen Detailseiten pro Modell.

Veroeffentlichte Website:  
https://ny-noe-e.github.io/
