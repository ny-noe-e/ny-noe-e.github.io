# Wireframe Desktop

**Breakpoint:** ab ca. 1181 px Breite  
**Zielgerät:** großer Desktop-Monitor  
**Seitentypen:** Startseite, Modellübersicht, Detailseite

## Grundprinzip

Auf Desktop nutzt die Website breite Flächen, ohne den Inhalt unnötig auseinanderzuziehen. Die Startseite wirkt stärker wie eine hochwertige Automotive-Präsentation. Die Modellübersicht nutzt drei Spalten, damit die zehn Fahrzeuge schnell vergleichbar sind. Detailseiten zeigen Text und Fahrzeugbild nebeneinander.

## Desktop-Regeln

- Modellübersicht mit drei Spalten.
- Hero-Bereich darf groß und bildlastig sein.
- Detailseiten zeigen Text und Fahrzeugbild nebeneinander.
- Stat- und Spec-Karten können in mehreren Spalten erscheinen.
- Inhalte bleiben trotz großer Fläche klar begrenzt und gut scanbar.
